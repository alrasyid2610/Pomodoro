# Pomodoro Timer

Aplikasi pomodoro sederhana (HTML/CSS/JS tanpa dependensi).

## Fitur
- Mode Fokus (25 menit), Istirahat Pendek (5 menit), Istirahat Panjang (15 menit)
- Istirahat panjang otomatis setiap 4 sesi fokus
- Mulai / Jeda / Reset / Lewati
- Durasi bisa diatur
- Bunyi + notifikasi browser saat sesi selesai
- Sisa waktu tampil di judul tab

## Menjalankan
Buka `index.html` langsung di browser.
